잠금화면이 바뀌지 않아요

도장은 잠금화면을 직접 바꿀 수 없어서, 단축어 앱의 개인 자동화가 대신 바꿔 줍니다. 아래를 차례로 확인해 주세요.

  1. 앱의 설정 → 월페이퍼 자동화하는 법을 끝까지 따라 했는지
  2. 자동화가 Run Immediately(즉시 실행)로 되어 있는지
  3. 단축어의 Set Wallpaper 동작에서 Show Preview와 Crop to Subject가 꺼져 있는지
  4. 앱의 설정 → 잠금화면 자동 업데이트가 켜져 있는지
  5. 설정 → 잠금화면에 보여줄 트래커가 꺼짐이 아닌지

도장 앱을 닫을 때 바뀌므로, 도장을 찍은 뒤 홈 화면으로 나가 보세요.

도장 앱을 닫을 때마다 'Unable to Set Wallpaper' 알림이 떠요

예전에 받은 단축어를 쓰고 있어서 그래요. 단축어 앱에서 기존 단축어를 지우고, 설정 → 월페이퍼 자동화하는 법에서 단축어를 다시 가져와 주세요.

위젯이 늦게 바뀌어요

iOS는 배터리를 아끼려고 위젯을 새로 그리는 횟수를 하루 단위로 제한해요. 위젯 버튼을 연달아 누르면 다른 위젯이 한동안 늦게 바뀔 수 있어요. 도장 기록은 바로 저장되고, 시간이 지나면 위젯도 다시 맞춰집니다.

싱글 트래커와 멀티 트래커는 무엇인가요

잠금화면에 캘린더를 놓는 두 가지 방식이에요. 싱글 트래커는 트래커 하나를 크게, 멀티 트래커는 2열 × 4줄 칸에 여러 트래커를 작게 보여 줘요. 멀티 트래커에서 21일·1달·100일·무기한 트래커는 세로로 두 칸을 차지해요. 설정 → 잠금화면에 보여줄 트래커에서 고를 수 있어요.

강아지친구들 스킨은 왜 싱글 트래커에서만 쓸 수 있나요

화면을 가득 채우는 그림 배경이라, 칸이 작은 멀티 트래커에서는 그림이 제대로 보이지 않아요. 강아지 배경일 때 멀티 트래커를 누르면 멀티 트래커에서 쓸 수 있는 배경으로 바꿔 넘어가요.

잠금화면 시계에 캘린더가 가려져요

잠금화면 시계는 서체와 크기를 바꿀 수 있어서 앱이 시계 높이를 알 수 없어요. 설정 → 잠금화면에 보여줄 트래커에서 미리보기를 보며 캘린더 위치와 캘린더 크기를 맞춰 주세요.

산 스킨이 보이지 않아요

설정 → 구매 복원을 눌러 주세요. 스킨을 산 Apple 계정으로 로그인돼 있어야 해요. 앱을 지웠다 다시 설치한 경우에도 같은 계정이면 산 스킨이 돌아와요.

기록은 어디에 저장되나요

도장 기록은 이 기기에만 저장되고 어디로도 보내지 않아요. 앱을 지우면 기록도 함께 지워지니 주의해 주세요.

앱 언어를 바꾸고 싶어요

설정 → 언어에서 고른 뒤 앱을 완전히 닫았다가 다시 열어 주세요. 위젯도 같은 언어로 바뀌어요.

My Lock Screen doesn't change

Dojang can't change your Lock Screen by itself. A personal automation in the Shortcuts app does it. Please check, in order:

  1. You followed Settings → How to automate your wallpaper in the app to the end
  2. The automation is set to Run Immediately
  3. In the shortcut's Set Wallpaper action, Show Preview and Crop to Subject are off
  4. Settings → Auto-update Lock Screen is on in the app
  5. Settings → Tracker on the Lock Screen isn't Off

The Lock Screen updates when you close Dojang, so stamp a day and go back to the Home Screen.

'Unable to Set Wallpaper' appears every time I close Dojang

You're using an older version of the shortcut. Delete it in the Shortcuts app, then add it again from Settings → How to automate your wallpaper.

My widgets update late

To save battery, iOS limits how often widgets can redraw each day. If you tap widget buttons many times in a row, other widgets may lag for a while. Your stamps are saved right away, and the widgets catch up over time.

What are Single tracker and Multi tracker?

Two ways to place calendars on your Lock Screen. Single tracker shows one tracker large; Multi tracker shows several trackers small in a 2 × 4 grid, where 21-day, month, 100-day and ongoing trackers take two slots. Choose in Settings → Tracker on the Lock Screen.

Why does the Puppy Friends skin work only with Single tracker?

Its background is a full-screen illustration that doesn't show properly in Multi tracker's small slots. If you tap Multi tracker with a puppy background, Dojang switches to a background that works there.

The clock covers my calendar

You can change the Lock Screen clock's font and size, so the app can't know how tall it is. In Settings → Tracker on the Lock Screen, adjust Calendar position and Calendar size while watching the preview.

I can't see a skin I bought

Tap Settings → Restore purchases while signed in with the Apple Account you bought it with. If you reinstall the app, your purchased skins come back on the same account.

Where is my data stored?

Your stamps stay on this device and are never sent anywhere. Deleting the app also deletes your records.

I want to use another language

Choose it in Settings → Language, then fully close and reopen the app. Widgets switch too.

ロック画面が変わりません

ドジャンはロック画面を直接変えられないため、ショートカットアプリの個人用オートメーションが代わりに変えます。次を順に確認してください。

  1. アプリの設定 → 壁紙を自動化する方法を最後まで進めたか
  2. オートメーションが Run Immediately（すぐに実行）になっているか
  3. ショートカットの Set Wallpaper アクションで Show Preview と Crop to Subject がオフになっているか
  4. アプリの設定 → ロック画面の自動更新がオンか
  5. 設定 → ロック画面に表示するトラッカーがオフになっていないか

ロック画面はドジャンを閉じたときに変わります。スタンプを押したらホーム画面に戻ってみてください。

ドジャンを閉じるたびに「Unable to Set Wallpaper」が表示されます

以前のショートカットを使っているためです。ショートカットアプリで既存のショートカットを削除し、設定 → 壁紙を自動化する方法からもう一度追加してください。

ウィジェットの更新が遅れます

iOS はバッテリーを節約するため、ウィジェットを描き直す回数を1日単位で制限しています。ウィジェットのボタンを続けて押すと、ほかのウィジェットがしばらく遅れることがあります。スタンプはすぐに保存され、時間がたつとウィジェットも追いつきます。

シングルトラッカーとマルチトラッカーとは？

ロック画面にカレンダーを置く2つの方法です。シングルトラッカーはトラッカー1つを大きく、マルチトラッカーは2列 × 4行のマスに複数のトラッカーを小さく表示します。マルチトラッカーでは21日・1か月・100日・無期限のトラッカーが縦に2マス使います。設定 → ロック画面に表示するトラッカーで選べます。

わんこフレンズのスキンがシングルトラッカーでしか使えないのはなぜですか

画面いっぱいに広がるイラストの背景なので、マスの小さいマルチトラッカーではきれいに表示されません。わんこの背景でマルチトラッカーを押すと、マルチトラッカーで使える背景に切り替えて移ります。

ロック画面の時計でカレンダーが隠れます

ロック画面の時計は書体やサイズを変えられるため、アプリには時計の高さがわかりません。設定 → ロック画面に表示するトラッカーでプレビューを見ながらカレンダーの位置とカレンダーのサイズを調整してください。

購入したスキンが表示されません

設定 → 購入を復元を押してください。スキンを購入した Apple アカウントでサインインしている必要があります。アプリを再インストールした場合も、同じアカウントなら購入したスキンが戻ります。

記録はどこに保存されますか

スタンプの記録はこのデバイスにだけ保存され、どこにも送信されません。アプリを削除すると記録も一緒に削除されるのでご注意ください。

アプリの言語を変えたい

設定 → 言語で選び、アプリを完全に閉じてからもう一度開いてください。ウィジェットも同じ言語になります。
